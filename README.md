# Лабораторна робота №3 — UART на Verilog

- **Студент:** Манько Денис Іванович, КІ-406
- **Варіант:** 10 — протокол UART, мова Verilog
- **Параметри:** кадр 8N1, 115200 бод, тактова частота 12 МГц
- **ПЛІС (етап 4):** Lattice iCE40UP5K-SG48 (плата iCEBreaker)
- **Інструменти:** Icarus Verilog + GTKWave (симуляція), Yosys + nextpnr (синтез, часовий аналіз) — OSS CAD Suite

## Структура
| Файл | Призначення |
|---|---|
| `rtl/uart_tx.v` | Передавач (Tx): FSM IDLE → START → DATA → STOP, дільник частоти |
| `rtl/uart_rx.v` | Приймач (Rx): синхронізатор, вибірка в середині біта, контроль стоп-біта |
| `tb/tb_uart.v` | Тестбенч: тести Tx, Rx, петля Tx→Rx, помилка кадру |
| `tb/tb_uart.gtkw` | Набір сигналів для GTKWave |
| `sim.bat` | Запуск симуляції та відкриття осцилограм |

## Запуск симуляції (Windows)
```
C:\oss-cad-suite\environment.bat
sim.bat
```
Очікуваний результат у консолі: `ALL TESTS PASSED`.
